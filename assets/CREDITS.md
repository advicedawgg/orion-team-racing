# Asset credits — Orion Team Racing

All generated art is original, made for this project on 2026-09-25.

## How it was made

- **Model: Krea 2 (`krea/krea-2-medium-turbo`), hosted, via OpenRouter `/api/v1/images`.**
  The plan was Krea 2 Turbo fp8 on Unraid's Arc B60 (ComfyUI `comfy-krea2`), but card1 had no
  room that night (see the `renderComfy` comment in `tools/gentex.mjs`), so every image below
  came from the same Krea 2 family through OpenRouter (~$0.015 each). `BACKEND=comfy` (the
  default) re-renders on the B60 when it has room.
- Generator: `node tools/gentex.mjs` (prompts, seeds, sizes live there; raw renders cached in
  `work/krea/`, which is gitignored). Post-processing: `tools/texpost.py`. Logo: `tools/logo.sh`.
- Seeds are fixed per asset and passed to the API, but the hosted endpoint does not reliably
  honour them — the raw cache, not the seed, is what makes a re-run reproduce the same file.
- Luma targets (`luma`) gamma-lift a texture to that mean luma; `flat` removes baked
  low-frequency lighting. Textures multiply material colour, so roads are kept mid-tone.
